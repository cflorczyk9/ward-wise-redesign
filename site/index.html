How it stays free.

Public data goes stale unless someone is paid to keep it current. Membership dues pay for that work.

  1. Organizations join

    Planners, community groups and businesses pay yearly dues sized to their budget.

  2. Dues fund upkeep

    Half of every dollar pays people to keep data feeds running and add each year's new records.

  3. The public site stays current

    Every resident gets the same up-to-date numbers, with no login and no charge.

  4. Residents improve it

    Resident nominations become new measures, which makes the data more useful to members.

The membership is called the Ward Wise Guild. How membership works

Built to be trusted.

The same method for every ward, and a source behind every number.

Every number cites its source

Each measure lists where it comes from, how it is calculated and which years it covers.

One method for all 50 wards

No ward is measured differently, and no member can change or hide a result.

No data about individuals

Ward Wise measures neighborhoods and holds no records about individual residents.

Open to check

The data is available through a public API, and the method is documented in full.
