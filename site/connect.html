Ward Wise

Ward Wise data in Claude.

Ask about any Chicago ward in plain English and get answers built from the same 271 public measures on this site, sources included.

The server

One address connects it.

This is the address for the Ward Wise server. It works with Claude and any other app built on MCP (Model Context Protocol, the open standard AI apps use to reach outside data). Copy it, then paste it where the app asks for a connector.

https://wardwise-redesign.netlify.app/mcp

In Claude

Add it in under a minute.

  1. Open Customize

    In Claude's sidebar, click Customize.

  2. Open Connectors

    Click Connectors, then the plus button.

  3. Add custom connector

    Paste the address from above and click Add.

  4. Start asking

    No sign-in and no extra settings. Ward Wise shows up as a connector right away.

In Claude Code

From the command line, this one line adds the same server.

claude mcp add --transport http wardwise https://wardwise-redesign.netlify.app/mcp

The fine print

What it can and cannot do.

It only reads what's already public on this site.

Read-only

It only reads the same public measures shown on this site. It cannot edit a ward, a boundary, or any number.

No sign-in

Anyone can connect with the address above. There's no account, no key, and nothing personal gets collected.

Some measures are modeled

A few, like fear of walking at night, are built from a national survey model. The server marks these as estimates, separate from the ward-level counts.

Every number has a source

Data comes from the Ward Wise API and the public records behind it, including the City of Chicago and the U.S. Census Bureau.
